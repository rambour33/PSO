Voir le profil start.gg ↗
Où trouver ma clé ?
  1. Ouvre start.gg → Paramètres du compte → Developer Settings.
  2. Clique sur Create new token, donne-lui un nom (ex. « PSO »).
  3. Copie le jeton et colle-le ci-dessus. Il n'est affiché qu'une seule fois sur start.gg.

Pour envoyer les scores, le compte doit être organisateur ou admin du tournoi.
